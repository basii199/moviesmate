# MoviesMate

MoviesMate helps users discover, browse, and track movies through a seamless interface. It solves the problem of scattered movie discovery by providing a centralized platform where movie enthusiasts can search for titles, watch trailers, and maintain personal watchlists all in one place. The application takes standard movie data and transforms it into a highly visual, personalized catalog tailored to individual preferences.

## Usage

Users can begin exploring the movie database immediately upon visiting the homepage. The main dashboard displays categorized carousels for trending, popular, and top-rated films. 

To find a specific film, type a query into the search bar in the top navigation. Submitting a search routes the application to a dedicated search results page displaying all matching titles.

By creating an account and logging in, users can curate their own collections. Navigating to any movie's detail page reveals "Favorite" and "Save" buttons. Clicking these buttons will store the movie in the user's secure database profile. Users can then view all their saved content by navigating to their personal Dashboard using the user menu in the top right corner.

The profile section allows users to upload a custom avatar image and update their display name. These changes reflect globally across the header and dashboard interfaces.

## Features

* **Movie Discovery**: Browse curated lists of popular, trending, and top-rated movies updated dynamically.
* **Advanced Search**: Find specific movies instantly using robust search functionality.
* **Detailed Movie Profiles**: View comprehensive movie data including cast lists, storylines, release dates, and embedded YouTube trailers.
* **Personalized Dashboard**: Save movies to custom bookmark and favorite lists for future viewing.
* **Secure Authentication**: Create accounts safely to protect personal lists and preferences.
* **Profile Management**: Customize user accounts with personal display names and custom avatar uploads.
